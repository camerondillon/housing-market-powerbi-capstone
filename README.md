# U.S. Housing Market Analysis

## MIS Senior Capstone Project

A college capstone project analyzing U.S. housing market data using Microsoft Power BI.

## Project Overview

This project examines housing market trends and differences across the United States. The analysis focuses on:

- Home prices by state and city
- Price per square foot
- Housing affordability
- Price-to-income ratios
- Living space
- Market density
- Regional differences
- Housing market rankings

The project involved transforming housing data into visual analysis, identifying key trends, and presenting findings to communicate data-driven insights.

## Tools & Skills

- Microsoft Power BI
- Data Analysis
- Data Visualization
- Business Intelligence
- Dashboard Development
- Data Storytelling
- Microsoft Excel
